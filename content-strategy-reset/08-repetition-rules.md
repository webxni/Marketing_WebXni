# Portfolio Repetition Rules

Before selecting a slot and again before saving, compare the candidate with the same brand and all Gabriel sibling brands.

| Collision | Scope | Cooldown |
|---|---|---|
| Exact normalized title | All siblings | 180 days |
| Same topic angle | Same brand | 60 days |
| Same topic angle | Sibling brand | 45 days |
| Same opening hook | All siblings | 90 days |
| Same city + service + angle | All siblings | 45 days minimum |
| Same offer structure | Portfolio | One active profile at a time |

The comparison includes drafts, pending approval, approved, ready, scheduled, posted, rejected repeated topics preserved as feedback, and approved future topic plans. Business-name substitution, reordered carousel steps, and superficial hook rewrites count as duplicates. A collision selects another approved unused slot; it never triggers open-ended research fallback.
